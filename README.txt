CoC Builder Calculator

Files:
- index.html: calculator app
- manifest.json: installable app metadata
- sw.js: offline cache
- icon.svg: app icon

To install on Android:
1. Upload these files to a public HTTPS website (GitHub Pages is a free option).
2. Open the website in Chrome on your Android phone.
3. Tap Chrome menu (three dots) > Install app or Add to Home screen.
4. Confirm. The app icon will appear on your home screen.

Note: PWA installation requires HTTPS hosting (localhost is the development exception).
